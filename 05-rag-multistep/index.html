01 · 검색 문맥과 절차 카드 비교

Top K는 유사도가 높은 문서 조각을 선택하는 개수입니다. 6개를 모두 검색해도 전체 순서를 명시한 관계가 추가되지는 않습니다. 질문 자체에는 네 단계 이름이 포함되어 있습니다.

원문 6개와 현재 검색 순위 · 문자 bigram 코사인
사람이 작성한 정적 절차 카드
아래 온톨로지 관계 추론 결과를 자동으로 넣는 기능은 아닙니다.

02 · 온톨로지 관계 추론


흩어진 정보를 관계 지도로 연결하면, 직접 적혀 있지 않은 순서도 알아낼 수 있습니다.
여기서 온톨로지는 단계 · 결과물 · 선행 조건을 공통된 이름과 관계로 표현한 것입니다.


알아보고 싶은 것위키를 만드는 일은 어떤 순서로 해야 하며,
앞 단계의 무엇을 다음 단계에 넘겨야 할까요?


1 · 입력사람이 알려 준 사실 7개
→
2 · 규칙관계를 연결하는 방법 3개
→
3 · 결과실제 실행 후 관계와 순서 확인


1. 어떤 정보를 넣나요?
사람이 입력한 사실입니다. 엔진이 문서를 읽어 알아낸 정보가 아닙니다.


2. 어떻게 연결하나요?
아래 규칙을 입력 사실에 반복 적용합니다.


  1. 선행 조건을 순서로 바꾸기
    “B를 하려면 A가 필요하다” → “A가 B보다 먼저다.”
  2. 순서를 이어 붙이기
    “A가 B보다 먼저”이고 “B가 C보다 먼저”이면 → “A가 C보다 먼저다.”
  3. 앞 단계의 결과물을 넘기기
    “B는 A가 필요”하고 “A가 X를 만든다”면 → “X는 B의 입력이다.”


새 관계를 더 이상 찾을 수 없을 때까지 연결합니다. 단계별 결과물 자체는 입력 사실이고, 어디로 넘길지를 규칙으로 도출합니다.


이 영역은 LLM을 호출하지 않습니다.


3. 그래서 무엇을 알게 됐나요?
아직 실행하지 않았습니다. 위 사실과 규칙을 입력해 실제 추론 결과를 확인하세요.


입력한 사실의 진위는 사람이 확인해야 합니다. 이 결과는 주어진 네 단계 예제의 관계이며, 위 RAG 답변 비교에 자동 주입되지 않습니다.
