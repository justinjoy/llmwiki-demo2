# Mini RAG Lab — 벡터 유사도 검색 데모

RAG의 검색(Retrieval) 단계를 살펴보는 웹 데모입니다. 질문과 문서를 문자 bigram 빈도 벡터로 바꾸고, 코사인 유사도로 문서 순위를 매기는 과정을 시각화합니다.

검색 대상은 코드에 정의된 문서 3개입니다. 모든 계산은 브라우저의 JavaScript에서 실행합니다. 문서 업로드·편집, Top K 조절, 외부 검색, LLM 답변 생성 기능은 없습니다. 의미 기반 신경망 임베딩이나 벡터 데이터베이스도 사용하지 않습니다.

## 실행 방법

### 로컬 웹 서버로 열기

Python 3가 설치된 환경에서 저장소 루트 기준으로 실행합니다. 추가 Python 패키지는 필요하지 않습니다.

```bash
cd 03-mimic-rag
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. 이미 이 디렉토리에 있다면 서버 명령만 실행합니다. 시연 중에는 터미널을 열어 두고, 종료할 때 `Ctrl+C`를 누릅니다.

8000번 포트를 사용 중이면 `python3 -m http.server 8001`로 실행하고 <http://localhost:8001>에 접속합니다. Python은 정적 파일을 제공하며 검색 API나 추론 서버로 동작하지 않습니다.

### 서버 없이 열기

`index.html`을 브라우저에서 직접 열어도 사용할 수 있습니다. `index.html`, `styles.css`, `rag.js`, `app.js`를 같은 디렉토리에 유지하세요. 인터넷 연결, API 키, npm 설치 또는 별도 빌드 과정은 필요하지 않습니다.

## 검색 대상 문서

| ID | 화면 이름 | 문서 내용 |
| --- | --- | --- |
| D1 | 환불 안내 | 환불은 구매 후 14일 이내에 가능합니다. |
| D2 | 배송 안내 | 배송은 결제 완료 후 보통 2~3일 걸립니다. |
| D3 | 회원 등급 | 회원 등급은 최근 1년 구매 금액으로 결정됩니다. |

웹 데모의 문서는 `rag.js`의 `DOCS`에 정의되어 있습니다. 화면 이름과 색상은 `app.js`, 비교 문서 선택지는 `index.html`에 따로 정의되어 있으므로 문서 수나 종류를 바꿀 때는 함께 수정해야 합니다. Python 참고 코드의 `DOCS`도 일치시켜야 비교 테스트가 통과합니다.

## 화면 사용법

1. 초기 질문인 **환불 배송 회원**으로 세 문서의 유사도를 비교합니다.
2. **환불 기한**, **배송 기간**, **회원 등급**, **함께 비교**, **관련 없는 질문** 버튼으로 예시 질문을 넣습니다.
3. 질문을 직접 수정하면 즉시 순위, 막대, 각도, 상세 계산이 갱신됩니다. 입력창의 최대 길이는 500입니다.
4. 문서 카드를 누르거나 **비교 문서** 선택지를 바꾸면 해당 문서의 bigram과 계산 과정이 표시됩니다. 직접 선택한 문서는 이후 질문을 입력해도 비교 대상으로 유지됩니다.
5. **유사도 비교** 버튼을 누르거나 Enter를 누르면 선택 고정이 풀리고 최고 순위 문서를 비교 대상으로 선택합니다. 예시 질문 버튼도 선택 고정을 해제합니다.

상세 비교 대상으로 고른 문서와 검색 결과는 별개입니다. 다른 문서를 선택해도 **가장 가까운 근거**에는 최고 순위 문서가 표시됩니다. 모든 점수가 0이면 **검색 근거 없음**으로 안내합니다.

## 시각화 읽는 방법

| 화면 | 의미 |
| --- | --- |
| 문서별 유사도 | 문서 3개를 유사도 내림차순으로 표시합니다. 점수는 소수 셋째 자리까지, 막대는 0~1 고정 척도로 표시합니다. |
| 각도로 보는 유사도 | 질문과 각 문서 사이의 각도입니다. 0°는 같은 벡터 방향, 90°는 공통 bigram이 없는 경우입니다. 문서끼리의 상대적 거리나 각도를 나타내는 2차원 투영은 아닙니다. |
| 질문·문서를 쪼개면 | 서로 다른 문자 bigram을 표시합니다. 공통 bigram은 색으로 강조하고, 반복되는 묶음에는 `×횟수`를 붙입니다. |
| N차원 사용 | 해당 텍스트에 등장하는 서로 다른 bigram의 수입니다. 전체 출현 횟수나 신경망 모델의 고정 임베딩 차원 수가 아닙니다. |
| 공통 N개 | 질문과 선택 문서에 모두 등장하는 서로 다른 bigram의 수입니다. 반복 횟수를 합산한 값은 아닙니다. |
| 코사인 계산식 | 공통 bigram의 빈도 곱을 더한 내적을 두 벡터 길이의 곱으로 나누는 과정을 표시합니다. |

유사도는 문자 패턴이 겹치는 정도이며 정답 확률이나 의미적 정확도 점수가 아닙니다. ‘검색 근거 없음’ 역시 이 세 문서와 공통 bigram이 없다는 뜻입니다.

## 계산 방식

`rag.js`의 검색 계산은 `mimic_rag.py`와 일치하도록 구현되어 있습니다.

1. 일반 공백 문자(`' '`)만 제거합니다. 탭·줄바꿈·문장부호는 제거하지 않습니다.
2. 연속된 문자 두 개씩 묶어 bigram을 만듭니다. 예를 들어 `환불 배송`은 `환불`, `불배`, `배송`이 됩니다.
3. 각 bigram의 출현 횟수를 벡터의 값으로 사용합니다. 문서 벡터는 스크립트를 불러올 때 한 번 계산하고, 질문 벡터는 입력이 바뀔 때 계산합니다.
4. 질문 벡터와 각 문서 벡터의 코사인 유사도를 계산합니다.
5. 점수 내림차순으로 정렬하고, 점수가 정확히 같으면 Python과 동일하게 문서 문자열의 유니코드 코드 포인트 순서를 내림차순으로 적용합니다.

```text
코사인 유사도 = Σ(질문 내 bigram 빈도 × 문서 내 같은 bigram 빈도)
                ÷ (질문 벡터 길이 × 문서 벡터 길이)

벡터 길이 = √Σ(각 bigram 빈도²)
```

화면의 동점 안내는 최고 점수와의 차이가 `1e-12`보다 작은 문서까지 포함합니다. 순위 정렬은 반올림 전 점수를 사용하므로, 표시된 점수가 같아 보여도 순위가 다를 수 있습니다.

공백 제거 후 문자가 2개 미만이면 빈 벡터가 되어 유사도는 0을 반환합니다. 이 경우 각도는 정의되지 않으므로 각도 그림 대신 입력 안내를 표시합니다.

## 시연 예시

- **환불 배송 회원**: D1 약 `0.108`, D2 약 `0.105`, D3 약 `0.100`으로 세 문서의 점수를 비교할 수 있습니다.
- 문서 문장 전체를 질문에 복사: 동일한 벡터이므로 해당 문서의 유사도가 약 `1.000`이 됩니다. 유사도 1이 항상 원문 문자열의 일치를 뜻하는 것은 아닙니다.
- **관련 없는 질문**(`오늘 날씨 어때요?`): 세 문서 모두 0이며 ‘검색 근거 없음’을 표시합니다.
- 빈 질문 또는 한 글자: bigram을 만들 수 없어 0점과 입력 안내를 표시합니다.

## Python 참고 코드

이 디렉토리에서 실행합니다. Python 3.9 이상을 사용하세요. 추가 패키지는 필요하지 않습니다.

```bash
python3 mimic_rag.py
```

초기 질문 `환불 배송 회원`의 문서별 점수와 최고 순위 문서를 터미널에 출력합니다. `answer()`라는 함수 이름을 사용하지만 LLM으로 답변을 생성하지 않습니다.

Python의 `answer()`는 모든 점수가 0이어도 정렬된 첫 문서를 출력합니다. 웹에서는 같은 상황을 ‘검색 근거 없음’으로 표시합니다. 검색 순위와 점수 계산은 같고, 결과 안내 방식이 다릅니다.

## 검증

Node.js 18 이상과 Python 3.9 이상이 필요합니다. `python3` 명령을 PATH에서 찾을 수 있어야 합니다. 이 디렉토리에서 실행합니다.

```bash
node --test tests/rag.test.cjs
```

현재 테스트 2개는 다음을 확인합니다.

- 예시 질문, 빈 입력, 한 글자, 반복 문자, 탭·줄바꿈, 이모지, 문서 원문에 대해 JavaScript와 Python의 순위 및 점수가 일치하는지
- bigram의 반복 횟수와 유니코드 문자 처리, 빈 벡터의 0점, 동일 문서의 1점, 관련 없는 예시 질문의 0점

이 테스트는 검색 계산을 검증합니다. 브라우저 화면 배치나 클릭·키보드 동작을 자동 검증하지는 않습니다. 웹 데모만 사용할 때는 Node.js가 필요하지 않습니다.
